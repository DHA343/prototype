# 画面端の水面

`edge_membrane.tscn` を開いてF6で実行する。既存のorbを利用した独立シーン。

## 操作

- 起動時からmainと同じマウス操作。orbの初期位置もマウス位置に合わせる。
- Space: マウス操作と自動デモを切り替える。デモは右・下・左・上・右上の角へ順に通過する。
- マウス操作では既存の追従移動、左クリックのブースト、右クリックのブレーキを利用する。
- R: orbを中央に戻し、歪みをリセットする。
- E: 歪みの表示を切り替えて比較する。
- H: 調整パネルを表示・非表示にする。

## 調整

画面左上のスライダー、またはMembraneノードのInspectorで調整する。
実行中のスライダー変更は保存されない。デモ速度は実行中のパネルから調整する。

| 項目 | 意味 |
| --- | --- |
| 波の強さ | 水面の屈折と反射の強さ。0で新しい波を起こさない |
| 基準速度 | 画面端へ向かう速度がこの値のとき、強度倍率が1になる |
| 強度の上限倍率 | 速度による倍率と、重なった波の振幅の上限 |
| 斜め方向への流れ | 縁に沿う速度を波へ伝える割合。0で方向への流れを止める |
| 縁に沿う広さ | 通過位置から上下または左右に減衰する広さ |
| 水面の帯幅 | 画面端から内側へ波が見える範囲 |
| 波の間隔 | 水面に重なる波の細かさ |
| 接近の反応距離 | orbの外周が画面端へ近づいたときに反応し始める距離 |
| 揺れる速さ | ばねの振動数 |
| 減衰 | 大きいほど早く収束する |
| デモ速度 | 自動デモの移動速度 |

## 構成と試作上の扱い

- Background → Distortion → Actors → Interfaceの順にCanvasLayerを描画する。
- Distortionは画面テクスチャを読むポストプロセス。後から描くorbと操作パネルは歪まない。
- 各辺に32点の連結したばねを配置し、通過位置からガウス状に弱まる力を加える。
  揺れは隣接点へ伝わり、角への接近では隣接する二辺が同時に反応する。
- ばねの振動エネルギーを水面の波の強さに変換する。縁の細い帯に複数の波を重ね、
  前後・横方向の屈折と薄い反射を描く。端には揺れる波頭の反射が一時的に現れる。
  波が減衰すると反射も消え、通常の背景に戻る。
- 外向きに動いている間に力を加え、離れた後や停止後は減衰振動する。
  画面内へ戻る動きでは新しい力を加えない。
- 画面端へ向かう速度成分で強度倍率を決める。縁と平行な移動は新しい波を起こさない。
  作用時間の短さで高速通過が弱くならないよう、反応領域を通過する距離に応じて力積を加える。
  前フレームからの経路を細分化して評価し、重なった波にも振幅上限を設ける。
- 斜め通過では、縁に沿う速度成分で波の分布を移流させる。通過後もその方向へ流れ、
  次第に減速する。流速は最大600px/s。画面の角に達した流れはその辺から抜ける。
- 揺り戻しで画面外を参照する部分は、端の映像を鏡映して補う。
- 背景は歪みを見比べやすい市松模様。本編への組み込みは行っていない。

画面テクスチャの読み取りは[Godot公式ドキュメント](https://docs.godotengine.org/en/stable/tutorials/shaders/screen-reading_shaders.html)を参照。
