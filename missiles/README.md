# 追尾弾

本編はボールがバンパーに衝突すると、バンパーの中心から Homing 1 を3発同時に発射する。
射出方向は弾ごとに360°から抽選する。

| 調整場所 | 内容 |
| --- | --- |
| `main/main.tscn` の `Playfield/MissileLauncher` | 弾シーン、発射数、発射間隔、拡散角度、初速の範囲 |
| `homing_1.tscn` のルート | 寿命、ダメージ、命中半径、貫通回数、射出後の減速・速度補間・折り返し |
| `homing_2.tscn` のルート | 寿命、ダメージ、命中半径、貫通回数、旋回・加速 |
| `Visuals` | 円形の本体、排煙、命中演出 |

`Projectile` が命中判定、貫通、寿命と描画の接続を担当する。追尾方式は各弾のスクリプトに置く。
追尾弾は物理フレームごとに更新する。同じ更新で当たった敵すべてにダメージを与え、
命中数に応じて残り貫通回数を消費した後、その更新の最後に消滅を判定する。
旧方式の弾シーンは `archive/` にある。
