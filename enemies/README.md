# 敵

編集するシーンは `main/main.tscn`。敵の設定は `enemies/enemy.tscn` にまとめる。

| 調整場所 | 内容 |
| --- | --- |
| Playfield/SpawnArea | 独立した矩形の位置・Size。盤面変更には追従しない |
| EnemySpawner | Enabled、Interval、Enemy Scene。初期は1秒間隔で1体 |
| EnemyのBody / Movement | 共通半径、球との反発係数、移動速度・加速度・経路更新間隔 |
| EnemyのCombat / Presentation | HP、ノックバックの上限・減衰・耐性、色、出現・被弾の伸縮、死亡音 |
| BallのEnemy Hit | ダメージ・ノックバックそれぞれの基本値と球速比例係数 |
| CrowdManager | 回避間隔、分離速度、重なり補正の強さ・速度上限 |

- 初期半径30px、HP100。表示・移動・被弾は同じ中心と基準半径を使い、演出の伸縮は判定を変えない。
- 初回はInterval経過後。以降はシミュレーション時間で等間隔に生成する。死亡・穴への退場は生成時刻に影響しない。
- 出現範囲内で16回まで候補を試す。壁・バンパー・球・他の敵と重なる、または穴への経路がない場合、その回を見送る。生成数は繰り越さない。
- 固定形状から半径別のNavigationPolygonを共有生成し、バンパーを迂回する。穴の先まで経路を作り、体全体が穴を通過すると退場する。フリッパーは動く衝突面として扱う。
- 群れの分離は旧実装の空間分割・近隣反発・重なり補正を基にする。狭い出口では目標に近い敵を優先し、対称な押し合いによる停止を解消する。
- 経路から押し出された敵は通行領域への復帰を試みる。スポーン時の領域確認とは区別する。
- ダメージは `Ball.damage + 球速 × Ball.damage_per_speed`。mainの初期設定は `50 + 球速 / 600`、ノックバックは `300 + 球速 × 0.2`。座標変更前と同じ打撃量になるよう、速度比例ダメージの係数は1/3に換算する。接触が続く間は再加算せず、離れて再接触すると再度打撃になる。致死接触でも球は反射する。
- 出現の成長時間中は球との接触を無効にする。死亡音は死亡時のみで、穴への退場では鳴らさない。
- 球の命中時は旧プロジェクトのヒット音を鳴らす。`pinball/hit.tres` をバンパーと共有し、接触継続中は重ねて要求しない。
- 穴への退場1体ごとに、下中央の固定ポイントから敵を追尾するミサイルを3発発射する。1発50ダメージ。設定は [ミサイル](../missiles/README.md) を参照する。

## 処理の入口

`Main.advance()` が独立したFlippersの更新、敵の進行方向、群れ補正、敵移動、球、退場、ミサイル、スポーンの順に更新する。独自の停止・スロー・コマ送りは持たず、渡された時間で更新する。

- Enemyだけが自身の位置を動かす。通常移動・ノックバック・群れ補正を `move_and_collide()` で解決する。
- EnemyRoutesは固定領域の経路を半径ごとに共有し、形状が変わった時に更新する。
- CrowdManagerは移動量を渡す。EnemySpawnerは出現範囲と生成時計を扱い、Mainが生成された敵へ経路と通知を接続する。
- Ballが反射と被弾通知を行い、EnemyがHP・ノックバック・死亡を処理する。死亡と穴への退場は共通の終了処理で一度だけ通知する。

`tests/enemy_test.gd` でスポーン時刻・見送り、経路・群れでの出口通過、壁・フリッパーの遮断、反射・ダメージ・死亡、生成時計を検証する。
