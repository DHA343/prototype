# 動作確認用の操作

- Eキーを押すたびに、カーソル位置へ通常の敵を1体召喚する。長押しのキーリピートでは増やさない。
- `main/main.tscn` の `Playfield/DebugSummon` が入力を受け取る。敵のシーン・生成先・登録通知は、参照するEnemySpawnerの設定を使う。定期生成の時計には触れない。
- 任意位置での確認用なので、通常スポーンの出現範囲・経路・重なりの事前検査は行わない。召喚後は通常の移動・戦闘・退場処理に従う。
- 無効化する場合はDebugSummonのProcess ModeをDisabledにする。
- 完全に削除する場合は、シーンのDebugSummonノードを削除して保存し、`debug/` フォルダを削除する。ゲーム本体のスクリプトやInput Mapを戻す作業は不要。
