# ピンボール調整環境

2026-11-24に、3条件打球と新接触だけの法線分離を本番へ反映した。[打球の実験](../experiments/flippers/shot_rules.md) と [組み合わせ検証](../experiments/flippers/evidence/separation_audit.md) は本番反映前の比較記録。

- 盤面を配置・実行するシーンは `main/main.tscn`。1920×1080基準、真上からの表示。
- 起動時のウィンドウと基準座標は1920×1080。Playfieldだけを640×360で描画して拡大し、ドットの見た目を維持する。
- 以前の640×360基準から位置・寸法・速度・加速度・距離のしきい値を3倍換算する。時間・角度・反発係数・ダメージは変えない。
- `Playfield/Boundary` を選び、Inspectorの数値で領域を調整する。原点は上壁中央。

## 領域

| グループ | 設定 |
| --- | --- |
| Playfield | `Width`：左右の壁の内側の間隔。`Height`：上壁から下端の基準までの高さ |
| Lower | `Opening Width`：穴幅。`Opening Offset`：Xは中央からの左右移動、Yは下端から上への距離。`Lower Angle`：水平から穴へ下がる角度 |
| Corners | `Upper / Lower Corner Radius`：上側・下側の接続角の丸み |
| Flipper Interval | `Start Distance`：外側接続点からの開始距離。`Opening Margin`：穴側の余白 |
| Flippers / Shape | `Root Width`：根元の太さ・支点円の直径。`Tip Width`：先端の太さ。左右共通、初期値36px / 18px。先端は根元以下に制限 |
| Flippers / Flipper Motion | `Swing Angle`：持ち上げ角度。`Raise / Return Speed`：上げる・戻す角速度 |
| Flippers / Shot Direction | `Root Angle`：軸側、`Tip Angle`：先端側の射出角度。真上が0度、右側は左右反転 |
| Flippers / Shot Power | `Power Equalization`：位置による回転由来の威力差を圧縮。0で補正なし、1で全区間が先端相当。初期値0.5 |
| Restitution | `Wall Restitution`：上壁・側壁・上角。`Lower Restitution`：下角・下側の接続部。フリッパーはFlippersの `Restitution` |
| Computed | 左右の接続高さ・下側直線長・有効なフリッパー区間長、角の半径の上限。すべて読み取り専用 |

穴幅・穴位置・角度を基準に、側壁との接続高さと直線長を計算する。設定値同士は書き換えない。穴幅変更時は外側からの開始距離を保ち、フリッパー区間長を伸縮させる。

`Opening Offset.y` が0なら穴は下端にあり、値を増やすと上へ移動する。下端はBoundary原点から `Height` 下の位置。計算結果はInspectorの通常更新で表示し、数値のドラッグ中に入力欄を再生成しない。

距離はpx、角度は度、角速度は度/秒。区間の距離は下側直線に沿って測る。外側接続点は角を丸める前の交点を指す。下側は直線で、壁の接続角だけを丸める。

区間が丸い角へ入り込む、または直線に収まらない場合は警告し、その区間の打ち返しを無効にする。入力値は保持する。角の半径が収まらない場合は警告し、Computedの上限まで丸める。

## 壁とフリッパーの接続

- `Playfield/Boundary` は `pinball/boundary.tscn` のインスタンス。固定壁と接続点だけを管理し、フリッパーを生成しない。
- `Playfield/Flippers` は左右共通の回転・打球・反発設定を持つ。子の `LeftFlipper` / `RightFlipper` は `pinball/flipper.tscn` のインスタンス。
- 各フリッパーの `Pivot Socket` / `Tip Socket` に、Boundaryの `LeftPivot` / `LeftTip` または `RightPivot` / `RightTip` を指定する。`Side` は左右の回転方向を指定する。
- 壁側の接続点は `Start Distance` / `Opening Margin` から自動配置する。接続点は直接移動せず、この2値で調整する。
- 壁側の `LeftPivot` / `RightPivot` は打球面の接続基準。実際の回転軸はそこから盤面の裏側へ根元の半径分ずらした位置で、フリッパーの `Pivot` と暗い点で示す。`Tip` は先端円の上面接点。編集時・実行時とも、壁側の両接続点から静止時の打球面・長さを合わせる。回転中は軸だけが固定され、打球面と先端は接続点から離れる。
- 見た目は根元と先端の円を包む凸形状で、円弧を32分割で近似する。衝突は別で、左右Xと下端Yを固定した四角形。上辺だけが回転に追従し、休止姿勢の最下端から下へ48 px追加する。各フリッパーの `Extra Thickness` で追加量を調整する。
- 見た目の先端の丸みは `Tip Socket` から先端半径分張り出す。当たり形状の左右端は休止姿勢の上辺端へ固定し、回転で穴へ張り出させない。穴幅84 px・球直径48 pxは維持する。
- 接続先が未指定、または壁の区間が成立しない場合は、そのフリッパーの表示・衝突を無効にする。

## 打ち返し・球

- Spaceで左右同時に、水色のフリッパーだけが根元の中心を軸に回転する。押している間は上げたまま、離すと元の位置へ戻る。静止した接続部は動かない。フリッパーの判定は内部も含む凸形状とし、固定壁の判定は従来の線分を使う。
- 上昇中は、軸側から先端側への接触位置で射出角度を線形補間する。角度は盤面の真上を基準にし、回転姿勢には依存しない。速さは接触点の回転速度・球の入射速度・反発係数から計算した反射速度の大きさを使う。指定方向が接触面へ戻る場合は強化用の表面速度で物理反射し、③を開始する。
- `Power Equalization` は上昇中の威力計算だけに使う。軸から先端までを0〜1とした位置を `補正量 + (1 − 補正量) × 位置` へ変換し、回転速度を計算する。接触判定と射出方向は実際の位置を使い、先端の強さ・球の入射速度・反発係数の影響を残す。
- 上昇中に、球が固定四角形の上辺または両端に接触し、面の物理表面速度に対して法線方向に接近していれば打球する。面の分類には既存の距離二乗許容差 `0.000004 px²` を使う。側面・下面、保持中・下降中の接近には通常反射を使う。
- 固定壁の通常反射はBoundaryの2種類の反発係数、フリッパーはFlippersの `Restitution` で調整する。0で静止面の法線反発なし、1で相対速度を保つ。バンパーは `Exit Speed` を最低速度とし、球の `Max Speed` が全体の上限。
- バンパーは `pinball/bumper.tscn` をPlayfield配下に配置する。整理用の親ノードの下にも配置でき、ノード名に指定はない。起動時に配下を再帰検索して登録する。共通の衝突設定・音は元シーンで管理し、位置・半径・色などは各インスタンスで変更できる。
- バンパーのInspectorの `Hit Animation` で `Hit Scale`（拡大倍率）、`Expand Duration`（拡大時間）、`Return Duration`（復帰時間）を調整する。初期値は0.05秒で1.2倍に膨らみ、0.15秒で戻る。当たり判定は変えず、連続衝突時は現在の大きさから演出を再開する。
- `ShotPrediction` は、今左右を押した場合の最初の接触を予測する。打球条件を満たし、指定方向が接触面の外を向く場合だけワールド座標の返球速度を返す。通常反射へフォールバックする場合や、別の物体に先に当たる場合は `Vector2.ZERO` を返す。打球の方向と速度は実際の応答と同じ `PinballFlippers` のAPIを使う。
- `ShotGuide` は予測を取得し、球の位置から返球方向を描く。`Main.predict_shot()` は既存の呼び出し用に委譲する。予測は最大1/240秒の刻みで進み、壁・Enemy・バンパーには照会時の姿勢を使う。

- 打球した対象は左右の板を下降まで通す（③）。次の物理更新で重力を適用した後のY速度が1 px/秒を超えたら復帰する。これは打球後の干渉防止であり、すり抜け防止とは別。無効中は予測線を表示しない。
- 抑制は③だけに統一した。下降して復帰した後は、同じ上昇中でも再打球できる。同じ側の打球記録による追加抑制は持たない。
- 回転板の独自接触は、更新開始時と現在の移動区間開始時の両方で同じ球と板が幾何的に非接触なら、`normal * (max(depth, 0) + 0.15)` で分離する。同じ更新内の再接触にも適用できる。開始時からの重なりと③解除時の既存重なりは真上へ解消し、停止した板はGodot標準の位置回復を使う。深い挟み込みと反復上限による移動打ち切りは未解決。
- `PinballFlipper` と `TableFlipper` が姿勢、接触面、表面速度を提供する。独自接触は描画用輪郭と独立した固定四角形のキャッシュを読む。`PinballMotion` が移動、相対接近、反射、位置分離を担当し、採用した独自接触に限り、走査と同じ経過時間で開始時の幾何を照会する。`PinballFlippers` が左右の管理、打球速度と③を担当する。

敵の生成・移動・戦闘の調整は [enemies/README.md](../enemies/README.md) を参照。

## 操作

| 操作 | 入力 |
| --- | --- |
| 左右同時 / 個別の打ち返し | Space / A・D、左右矢印 |

ゲーム本体は物理ティックごとに一回更新する。予測には専用の刻みを使う。検出Bの途中姿勢検査、接触後の残り経路の再検査、独自接触と標準接触を合わせた最大8回の反復を維持する。調整内容はGodotのLocal側で保存する。

`physics_test.gd` は盤面設定・接続・反射・30/60/120 Hzの回帰を検証する。`flipper_test.gd` は一更新の時間刻み、3条件と両端、新接触と既存重なり、複数対象の共通移動と③、予測を検証する。`render_test.gd` は解像度、描画輪郭、ポストプロセス、予測線の表示を検証する。

```powershell
godot --headless --path . --script res://pinball/tests/physics_test.gd
godot --headless --path . --script res://pinball/tests/flipper_test.gd
godot --path . --script res://pinball/tests/render_test.gd
```

過去の実験記録に記載された `migration_test.gd` と `minimal_test.gd` の現行回帰は `flipper_test.gd` で実行する。
