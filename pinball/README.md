# ピンボール

## 盤面とフリッパー

盤面の壁とフリッパーは独立している。壁側の接続点は静止時の打球面を定義し、フリッパーの実際の回転軸は根元半径分だけ内側にずらす。盤面の形状を変更しても、接続点を基準に静止時の打球面がつながるようにする。

フリッパーは描画形状と衝突形状を意図的に分けている。

- **描画形状：** 根元と先端に丸みを持つ形状。
- **衝突形状：** 左右端と下端を固定し、上辺だけが回転に追従する四角形。

衝突形状を固定するのは、フリッパーの回転によって開口部へ当たり判定が張り出すことを避け、球が通過する幅を保つためである。描画形状と衝突形状を一致させることは前提としない。

## 打球と衝突

### フリップ打球

方向指定付きのフリップ打球は、以下の3条件がすべて成立した場合に行う。

1. フリッパーが上昇中である。
2. 球が衝突形状の上辺または両端に接触している。
3. 球が接触面の物理表面速度に対し、法線方向へ接近している。

側面・下面への接触や、保持中・下降中の接触は通常の物理反射とする。

打球方向は接触位置に応じて根元側と先端側の設定角度を補間する。速度の大きさには、入射速度、フリッパーの表面速度、反発係数を反映する。威力の位置差は `Power Equalization` で調整する。

指定方向が接触面の内側を向く場合は、方向指定を適用せず、打球用の表面速度による物理反射を使用する。この場合も打球後の通過保護を開始する。

### 打球後の通過保護

打球直後の球がフリッパーへ再接触し、意図した軌道を失うことを防ぐため、球が下降を始めるまで左右両方のフリッパーとの衝突を無効化する。

この状態は球ごとに管理する。解除後は、同じスイング中でも打球条件を満たせば再打球できる。打球履歴による追加の抑制は設けない。

通過保護中にEnemyなどで球が反射されると、フリッパー内部へ戻った状態で保護が解除される場合がある。早期解除にも再打球や軌道変化の副作用があるため、現在は打球直後の軌道保護を優先する。

### 位置分離

回転中のフリッパーへの独自接触は、**物理更新開始時と現在の移動区間開始時の両方で非接触だった場合だけ**、接触法線方向へ分離する。同じ更新内で離れてから再接触した場合も、この条件で判断する。

開始時から接触・重なりがある場合は既存の上向き分離を維持し、停止したフリッパーではGodot標準の位置回復を使用する。

新接触で法線分離を使うのは、側面・下面への浅い接触に対して不必要に大きな上向き補正が生じることを避けるためである。既存重なりの扱いまで一律に変更するものではない。

## 予測線

予測線は、**今フリッパーを操作した場合に成立する、方向指定付きフリップ打球の方向**を示す。

通常の物理反射を予測して表示するものではない。フリップ打球が成立しない場合、指定方向が内向きで物理反射へ戻る場合、別の物体が先に接触する場合、通過保護中などは表示しない。

実際の打球と予測は同じ方向・速度計算を使用する。未来の接触位置は近似的に求めるため、予測線は将来の球の軌道を保証するものではない。

## 既知の制約

- **通過保護の解除：** 球がフリッパー内部へ戻ってから衝突が再有効化され、大きな位置補正が生じる場合がある。
- **近接した複数物体：** フリッパーとEnemyなどの間で接触が繰り返され、1更新の接触処理上限に達する場合がある。
- **回転中の接触検出：** 途中姿勢の離散的な検査を使用するため、接触時刻の誤差や打球の取りこぼしが残る。

いずれも現状の制約として把握しており、回復方式の全面変更や反復上限の拡大は採用していない。
