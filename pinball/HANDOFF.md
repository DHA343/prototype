# フリッパー移植後の引き継ぎ

2026-11-21。決定済みの形状・補正・無効化と共通化をmainへ移植した。実験の推奨案を、そのまま採用決定として移植していない。

## 移植したもの：目的を分ける

| 区分 | 現在の仕様 |
| --- | --- |
| 当たり形状・厚み | 左右Xと下端Yを固定した四角形。上辺だけがフリップに追従。休止姿勢の最下端から下へ48 px追加。穴幅84 px・見た目・接続位置は維持。厚みは通過しにくくする補助で、単独のすり抜け防止の保証ではない |
| 埋まり対策 | 回転途中の検査で重なった対象は真上へ分離。分離距離は16回の二分探索、余裕0.15 px。停止した板はGodot標準の位置回復。これは既に重なった対象を出す処理で、途中で接触を見つける処理とは別 |
| 打球後の干渉防止（③） | 打球した対象だけ、左右両方の打球・通常反射・位置回復を無効にして通す。次の内部更新の重力適用後のワールドY速度が1 px/秒を超えたら復帰。固定タイマー・外部衝突通知は使わない。これはすり抜け防止ではない |
| 共通化 | `PinballMotion` が移動・フリッパー応答・対象別の衝突除外を担当。無効化状態は `PinballFlippers` が対象IDごとに所有。Ballは描画・敵へのダメージ・バンパー・音等の固有処理を担当。既存Enemyの移動・AIは変更していない |
| 表示 | mainの丸い先細りの見た目を維持。赤い判定表示・球の色変更・表示切替UIは追加しない。予測線は新形状を使い、③の無効化中は出さない |

無効化は球全体・フリッパー全体のレイヤーを切る実装ではない。1対象の打球で他の対象は無効化されない。対象のリセット・削除でその状態を破棄する。

## 既存のまま残したもの：今回新たに選定したものではない

- **すり抜けの検出**：球の半径を含む経路の検査と、回転する板を同じ時刻の途中姿勢で調べる検査。
- **全体の時間分割**：mainの最大1/240秒＋回転速度・半径による追加分割を維持。分割撤去は有力案までで、ユーザーが採用を確定していないので今回は変更していない。
- **接触後の移動**：接触点で応答し、残り時間の新しい経路を調べる最大8回の既存ループ。8回が最適と決まったわけではない。
- **返球**：根元・先端の指定角、入射速度・回転速度・反発係数・威力均等化による計算を維持。同じ側への上昇中の再打球抑制も共通部品が担当。

「時間を細分化する」「接触する対象を探す」「重なりを解消する」「反射後の経路を調べる」「打球直後の干渉を止める」は別の処理。まとめて一つのすり抜け対策として説明・評価しない。

## 採用していないもの

- 更新後の板に球の経路を当てるだけで、回転途中の検査を置き換える案。
- 開始点から、反射を加味して計算した終点へ直接移動する案。本来外れる敵への誤ダメージと、本来当たる敵の接触漏れを再現した。
- 接触区間を追加4回／12回絞り込む精度改善、反復上限2回／4回への変更。
- 固定打球ライン、固定時間の無効化、外部衝突で無効化を解除する処理、入力予約の新設。

## 次に扱う未解決事項

1. **埋まりと反復**：近い敵に挟まれると、位置補正が反復上限を使い切り、残り時間の移動を捨てる。8回でも残る。補正中は位置が動くため、全てを無駄な再接触と決めつけない。経路検査と食い込み解消が同じ上限を使っている構造を分けて検討する。
2. **③の解除**：近い敵で反射した球が、板の内部にいる間に下降して復帰する場合がある。上向きのまま戻る球は無効のまま。解決済みと扱わない。
3. **精度・負荷の整理**：全体分割を外すか、接触区間を絞るか、反復上限をどう扱うかは未採用。位置・角度の精密な再現より、本来の対象への接触と自然なゲーム的返球を優先する。
4. **返球速度の調整項目**：根元・内側の速度を独立した数値で指定する項目は未実装。現状はmain由来の威力計算。
5. **既存の敵経路テスト**：20秒以内の脱出試験1件が失敗。フリッパーだけ旧形状へ戻した比較でも同じ失敗で、速度30 px/秒・終了位置約(1018,705)。速度や試験時間を今回勝手に変更していない。

位置補正の見た目や深い食い込みは、既存の「気になった段階で改善する」方針を維持する。未解決のものを、移植によって直ったことにしない。

## 実装箇所

- `main/main.tscn`：③を有効化。`main/main.gd`：無効化中の予測線を抑制。時間分割は既存のまま。
- `pinball/flipper.tscn`、`pinball/table_flipper.gd`：本番用の固定四角形・厚み・上辺と側面下面の速度・上向き分離距離。側面・下面は表面速度0。
- `pinball/flipper.gd`：見た目・回転・途中姿勢の検査。形状別の分離処理を呼ぶメソッドを追加。単独でEditorに開いた場合の親なし参照も修正。
- `pinball/flippers.gd`：③の対象別状態と解除、打球方向・威力設定。
- `pinball/motion.gd`：CharacterBody2Dを使う共通の移動部品。Ball型や外部衝突通知に依存しない。
- `pinball/ball.gd`：共通部品へ委譲。敵へのダメージ・バンパー・音はここに残す。

別種類の球のような対象は、円形のCollisionShape2Dを持つCharacterBody2Dに `PinballMotion.new(body)` を接続し、半径・重力・速度上限・boundary・flippersを設定する。同じ内部更新のdeltaとswingsでadvanceする。フリッパー用の個別処理・衝突通知を種類ごとに複製しない。円以外の形への一般化はしていない。既存Enemyが自動でこの部品へ切り替わったわけではない。

## 検証

- 移植専用 `pinball/tests/migration_test.gd`：96件成功。専用スクリプトなしのCharacterBody2D、半径6/24/36の20対象、状態分離、下降復帰、削除・リセット、上向き分離、mainの予測線を確認。
- 既存 `pinball/tests/physics_test.gd`：4,367件成功。変更前の丸い当たり形状を前提にした検査を、新しい四角形と上辺速度の仕様へ更新した。
- 比較プレビュー `experiments/flippers/tests/contact_preview_test.gd`：95件成功。
- `enemies/tests/enemy_test.gd`：上記の経路試験1件失敗。他の3,736件は成功。
- Godot AIでmainのシーン構造・配置・厚み48・描画と実行を確認。

実験の詳細は `experiments/flippers/evidence/contact_audit.md`。そこにある推奨と、この文書の移植済み・採用済み仕様を混同しない。古いREADMEの「main未移植」は移植前の記録。

今後の応答も、開始時に認識・不明点・進める前提を短く示す。実装前に変更対象と目的を報告し、推奨をユーザーの決定へ勝手に格上げしない。
