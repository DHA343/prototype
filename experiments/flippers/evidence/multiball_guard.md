# ③・④の複数球検証

## 結果

球ごとの無効化管理は、今回の20球・50球試験で独立して機能した。更新順を逆にしても、球の位置・速度・無効化状態は一致した。ただし、位置補正と短期限の再有効化に関する問題は残る。

Godot 4.7.2、最大1/240秒の内部更新、固定幅・追加厚み48 px、mainと同じ穴幅84 px。ボール同士は現在のmainと同じく衝突しない。敵は含めない。各試験は自動復帰を無効にし、落下した球を再投入しない。主試験28条件・初期配置延べ650球分、別世界に更新順を逆転した対照と代表1球だけの対照を置く。機械的検査252件で失敗0。

| 比較内容 | ③ 下降まで | ④ 40 msまたは下降まで | 補足 |
| --- | --- | --- | --- |
| 球ごとの状態の混線 | 0件 | 0件 | ④5 ms・100 msも検出なし |
| 無効化中のフリッパー接触処理 | 0件 | 0件 | 停止中の標準衝突・回転中の独自判定の両方を監視 |
| 更新順を逆にした結果との差 | 0 | 0 | 位置・速度・無効化状態が一致 |
| 板の下への通過 | 0球 | 0球 | ④5 ms・100 msも0。下記の限定した検出条件 |
| 内部で期限切れにする人工試験での再打球 | 0/20球 | 0/20球 | **④5 msでは18/20球**。最大補正約69.05 px |
| 全試験での最大補正 | 約91.08 px | 約91.08 px | 通常の20球一斉打球でも発生。完全に自然な見た目という評価ではない |
| 接触上限8回に達する更新 | あり | あり | 無効化中の接触ではなく、通常壁・有効なフリッパーの反復 |

## 試験条件

③、④40 ms、④5 msで次の9条件を実施した。追加で④100 msの近接反射板試験を行い、計28条件。

| 条件 | 球数・時間 | 初期状態・入力 |
| --- | --- | --- |
| 通常落下、3配置 | 各20球・8秒 | seed 11/29/73。x=610〜1310、y=180〜760、横速度±400、下向き0〜500 px/s。0.55秒周期で左右を80 ms押す |
| 半径混在 | 20球・8秒 | 半径6/15/24/36 px。通常落下と同じseed 11 |
| 左右の時間差入力 | 20球・8秒 | 右を0.275秒ずらす。それ以外は通常落下と同じ |
| 近い反射板からの戻り | 20球・6秒 | 試験専用の水平壁、中心(960,850)、幅720・厚さ12 px。左右上辺の広い範囲から下向き300 px/sで開始 |
| 上辺から一斉打球 | 20球・4秒 | 左右10球ずつ、上辺15〜82.5%の位置から下向き300 px/s。球同士の重なりによる反射はない |
| 球数の追加負荷 | 50球・8秒 | 通常落下と同じseed 11 |
| 内部で再有効化 | 20球・0.2秒 | 左右上辺の30 px下、上向き600 px/s、無効化済みを直接設定して開始。実際の打球から到達した状態ではない |

別に20球の状態分離試験を実施した。同じ右フリッパーに対し、無効化済みの上昇球10、未無効化の下降球5、無効化済みの下降球5を同時に置いた。上昇球だけ通過し、下降球は無効化の有無によらず捕球した。下降解除は5球だけに発生。各球の期限は他の19球の更新で進まず、球数削減・削除後の状態残留もなかった。

④100 msの近接反射板では71打球に対し下降で69回、時間で2回解除した。期限前に下向きへ変わった球の復帰も通った。

## すり抜けの検出範囲

「板の下への通過」は、球の中心が固定下端Y＋半径を下向きに横切り、その横切ったX位置で球全体が左右いずれかの板の幅に収まる場合に数える。中央の穴からの落下は数えない。板の側端に球が一部だけかかる場合や、浅い一時的な侵入をすべて検出する指標ではない。0件はあらゆる接続部分・形状・速度でのすり抜け防止を保証しない。

速度300 px/s超で移動が0.001 px未満となる更新が連続する現象も監視し、今回は検出しなかった。遅い球の静止全般や、あらゆる挟み込みを否定する検査ではない。

## 残った問題

- **短い時間切れによる再打球**：内部から開始した④5 msで18/20球を再打球。③・④40 msではこの条件の再打球は0だが、40 msなら常に安全という意味ではない。再有効化時に内部にいる球の扱いは未解決。
- **大きな補正**：全設定で最大約91.08 px。内部試験以外にも一斉打球で発生する。無効化状態の混線はなく、球ごとの接触・分離の問題として残す。
- **接触の反復**：壁Lowerや停止中の左右フリッパーで同じ接触を繰り返し、1内部更新の8接触上限に達した。8回に達しただけで全時間を失ったとは扱わず、元の移動計算と同じ微小移動の閾値で消費時間を追跡した。全条件の最大打切り時間は1球・1内部更新あたり約1.293 ms。停止が続く現象は検出しなかったが、余分な処理と一部の移動時間の打切りは残る。無効化方式は変更していない。
- **1球だけの対照との差**：近接反射板の4条件だけで、3.8417秒時点の通常壁Lowerとの接触法線に差が出た。接触点の差は約0.0002 px、最初の位置差は約0.001 pxで、その後の最大位置差約0.457 px・速度差約4.114 px/s。差が出る前の無効化状態は一致し、20球の更新順逆転では差が0だった。無効化の混線とは判定せず、標準の通常壁接触に差がある試験として記録する。検査では完全一致と区別し、最初の差が両方の同じ通常壁への接触法線差であることを確認する。

CPU時間はJSONに保存した値も計測用の接触記録処理を含み、描画を含まない。描画付きプレビューのFPSや本番性能としては扱わない。

