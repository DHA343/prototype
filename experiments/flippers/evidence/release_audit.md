# ③解除時の回復：現行・解除延期・小さい安全分離（2026-11-23）

## 判断

今回のB（解除延期）とC（安全な小補正）は、そのまま本番採用しない。解除延期は既知の打ち切りを避けるが、下降中の板下通過と長期未解除が生じる。安全分離3/6/12 pxは浅い重なりを処理できるが、既知の深い重なりを解消できず試行が終了する。途中終了を打ち切り改善と数えてはいけない。

打球は3条件、新接触の法線分離・検出B・③の左右共通管理・上向き探索16回・共有8接触を実験基準として維持。本番のmain、PinballMotion、PinballFlippers、TableFlipper、Enemyは変更していない。

| 構成 | 近接84配置の完走 | 未解消終了 | 接触上限へ到達した配置 | 最大補正 px |
| --- | ---: | ---: | ---: | ---: |
| 従来B | 84 | 0 | 3 | 68.38831 |
| 実験基準・現行解除 | 84 | 0 | 2 | 60.60965 |
| 解除延期 | 84 | 0 | 0 | 2.18924 |
| 安全分離3 px | 63 | 21 | 0 | 2.87757 |
| 安全分離6 px | 64 | 20 | 0 | 3.14266 |
| 安全分離12 px | 65 | 19 | 0 | 9.14915 |

安全分離の最大値には終了前までの通常接触も含む。失敗した更新は球の位置・速度を変更せず終了し、残りの試験時間は未実行である。安全分離の『接触上限0』と現行の完走84配置を直接比較して優位とは扱わない。

## 実装した候補の定義

- **現行解除**：重力適用後のY速度が1 px/sを超えれば、重なりにかかわらず左右の③を解除する。
- **解除延期**：既存の下降条件を満たし、両フリッパーとの幾何的接触がなくなった更新開始時に解除。待機中にEnemy等で上向きに戻った場合も、下降条件を満たすまで再有効化しない。左右別の解除は導入しない。
- **安全分離**：下降条件を満たした更新開始時に、初期接触の法線方向と上下左右の有限候補を試す。上限はユーザー指定の3/6/12 px。法線候補は深さ＋0.151 px、軸方向は開始時の四角形の外接範囲から円全体が退出する距離。短い順に調べ、補正先で左右両板・周囲の物体と接触せず、補正経路も安全な最初の候補を使う。

0.151 pxは従来の0.15 pxに丸め誤差対策0.001 pxを加えた実験値。板の補正先と物理世界の安全照会は0.03 pxの余裕を使用した。有限候補の最短であり、世界全体の最短安全位置を保証する探索ではない。

安全な候補がない場合は、ユーザー指定どおり未解消としてその試行を終了。延期・真上への大移動へ自動切替しない。補正自体は速度・打球・③開始を発生させず、再有効化後の通常接触は共通の3条件で処理する。

## 時刻と周囲の安全性

③の解除フックを実験側のフリッパー管理部品へ置き、Godotの移動・位置回復クエリより前に処理した。球は更新開始位置、回転板は回転計画の開始姿勢、停止板はその姿勢を使う。更新終了姿勢との混在は避けた。Enemy・壁は現在のBが照会する物理世界を使い、Enemyの過去姿勢の復元はしていない。

補正経路では、新規物体への進入をスイープで検査。開始重なりはスイープだけでは検出できないため、前後の照会を併用する。既存の障害物との重なりから退出する候補は許可するが、接触点対から求めた法線へ逆行する補正と、補正先に重なりを残す候補は不採用とした。開始重なりの凹形状は今回未対応として候補を棄却する。別板も開始姿勢の形状で経路検査する。照会結果128件上限では安全とせず候補を棄却する。

照会の仕様は [Godot公式 PhysicsDirectSpaceState2D](https://docs.godotengine.org/en/stable/classes/class_physicsdirectspacestate2d.html)、接触点対の法線・深さは [Godot公式 Shape2D](https://docs.godotengine.org/en/stable/classes/class_shape2d.html) を参照した。補正時点の安全性を調べるもので、後続の通常移動や他物体の将来の移動まで安全を保証するものではない。

独立した検査で、前後とも非接触の薄壁横断を棄却、開始重なりから外へ出る補正は許可、既存物体の反対側へ貫く補正は棄却することを確認した。直接回復の浅い／深い条件で、速度不変、補正上限、失敗時の位置不変と③維持も検査した。

## 解除延期の副作用

近接84配置での最大延期は200.000 ms。下降条件を満たして延期中に板下を通過したものは11イベント、11配置だった。これは今回の固定配置で観測した通過で、通常プレイの発生率でも、すべてが望ましくない通過という評価でもない。

低速内部（重力0、Y速度2 px/s）と、初回の延期後に速度0へ固定する専用条件では、2秒後も③が解除されなかった。後者は外部から速度を固定する診断条件であり通常プレイを模した発生率試験ではないが、待機に自動終端がないことを示す。

反対側進入の専用条件では、左板の内側端付近から右へ3,600 px/sで進めると、延期中の最初の更新で右板へ進入した。左右をまとめて無効にする副作用である。別板だけ再有効化する処理は追加していない。

## CPU負荷と照合

イベント履歴、面分類、前後の周囲観測、候補ログを外した実験Motionで、`ball.advance()`全体を測った。安全性に必要な接触・経路照会は含む。初期化とリセットは計測外。各巡の方式順を巡回し、各構成12,096サンプル（1,728×7）を集計した。診断版との位置・速度・未解消判定の照合8,640組は一致。

機械検査199,223件、診断なし版の照合等34,568件、既存migration回帰96件で失敗0。最終CLIログのSCRIPT ERROR/ERRORは0。本番8ファイルのSHA-256を前後と最終集計で確認した。

Godot AIの描画付き実行でも6方式を切り替え、浅い/深い解除12ケースで位置・速度・未解消・③の状態がCLIと一致。確認後は実行停止し、mainや起動設定は保存していない。

## 次の判断

- 3条件と新接触の法線分離は実験基準として維持する。本番は現状維持。
- 解除延期を採用するには、下降中の通過と未解除をどこまで許すかというゲーム仕様の判断が必要。
- 安全な小補正は浅い重なりに限定した候補として残るが、今回の深い内部からの復帰手段にはならない。
- 深い内部では『通過を継続するか、大きい補正を許すか、別の復帰規則を選ぶか』を先に決める。失敗時の暗黙フォールバックや反復上限の拡大は追加しない。
