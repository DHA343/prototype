# D1の四角形専用計算とD2の接触時刻探索

2026-11-21、Godot 4.7.2。変更は `experiments/flippers/` 以下だけ。本番のmain、PinballMotion、TableFlipper、Enemy、返球計算、③、上向き分離16回、接触上限8回は変更していない。停止中のGodot標準も維持し、B′には戻していない。

**現時点ではBを維持する。D1は独立した幾何参照に一致したが、明確な軽量化は確認できなかった。D2は最初の接触の精度を改善し、追加条件で見つかったBの打球状態不一致17件を解消した。一方、辺・角を重視した条件では検出時間が約3.5倍となり、同じ応答ループに接続すると移動打ち切りも増える。D2は検証候補として残すが、そのまま本番へ採用しない。**

## 1. D1：同じ姿勢で接触計算だけを比較

[quad_contact.gd](../quad_contact.gd) は上辺への射影と、固定された側面・下面への座標のクランプで最短点を求める。内部判定はX範囲・下端・上辺の半平面で行う。上面だけでなく側面・下面・角も扱う。接触しないと分かった場合は法線や打球情報を計算しない。

点・法線・食い込み量に加え、同じ式の表面速度・打球状態を返す。内部判定のために見た目の多角形を一時差し替えたり、中心を逆変換して汎用の内外判定へ渡したりする処理は使わない。

### 条件と結果

- 既存2,628条件のうち回転計画がある2,484条件について、Bの4 px間隔と停止境界を含む全ての検査時刻を再現。最初の接触後の時刻も調べる。
- 前回の開始時重なり288条件と、停止中の辺・角2,016条件の開始・中間・終了位置も追加。
- 計80,235照会で球を動かさず比較した。
- 独立参照は世界座標の4辺への距離と、4辺の外積による内外判定。BとD1が同じ結果であることだけを正解にはしない。

| 評価 | 結果 |
| --- | ---: |
| 接触有無のB/D1不一致 | 0 |
| 2,484回の経路検査の接触有無・最初の打球状態不一致 | 0 |
| 独立参照に対するD1の不一致 | 0 |
| B/D1で接触点・法線等がしきい値を超えて異なる照会 | 126 |

最後の126件は単に無視しない。判定に用いた量と生データを保存した。

- **124件：内部で最短の辺が並ぶ。** 辺までの距離差が0.001 px以内で、浮動小数点の変換差によって選択する辺が変わる。法線や接触点が大きく変わっても、どちらもほぼ同じ距離の分離面になる。D1の独立参照との確認ではこの曖昧さを別扱いにした。ゲームの応答まで同じになるという意味ではない。
- **2照会：Bの内外判定が参照と違う。** 同じ中心座標 `(870.024292, 992.206055)`、半径24。上辺から内部へ約0.00183 pxの位置で、Bは外側として下向きに近い法線、D1と独立参照は内部として上辺の外向き法線を返す。打球状態も変わる。ただし、今回の最初の接触としては選ばれず、2,484回の最初の接触結果は一致した。本番のBを修正してはいない。

独立参照との幾何比較では、接触境界±0.001 px、内部での同距離の辺、中心と辺の距離0.0015 px未満での法線の数値的不安定さを区別して記録した。今回の中心と辺の距離の近接フラグに該当するものは0。深い内部の最短面の選択を、球が最初に当たる位置の精度と混同しない。

## 2. D2：固定間隔を使わない接触時刻探索

[continuous_swing.gd](../continuous_swing.gd) は、円と四角形の隙間 `gap` と、その隙間が縮む速さの上限 `L` を求める。接触まで安全に進める時間の0.9倍、`0.9 × gap / L` だけ進め、繰り返す。時刻の間隔を4 pxや一定時間には固定しない。

上辺の両端は固定X上を上下するため、剛体回転の先端速度をそのまま速度上限とはしない。親の線形変換をP、上辺のローカル法線を回転させて `n=P^-T(-sin θ, cos θ)` とすると、上辺は `top_y=(k-n.x*dx)/n.y`。この微分の上限から上端2点のY速度を押さえ、球速度との合計をLに使う。辺上の点は頂点の補間なので、凸形状の移動にも同じ上限を使える。

接触許容距離は0.0005 px。これは参照の接触情報を表現する際の半径余裕と同じ値。接触区間を二分探索する処理は加えていない。最大2,048回、進行が1 ns未満、上辺が垂直になる区間などは「未解決」を返し、非接触成功へ数えない。

近接した位置で離れる向きの接触に対しては、再接触しないことを確認できる範囲だけ非接触とする。静止した凸形状から外向きに進む直線、固定された左右・下端の外側へ離れる直線が該当する。回転する上面等で証明できない場合は未解決とする。初回の統合でこの区分が不足していたため追加し、以下は再検証後の結果。

### 入力と参照

- 既存876入力×30/60/120Hzの2,628条件を使用。D2の検出比較は、そのうち回転計画のある2,484条件。停止中144条件は標準のまま、後の応答比較で確認した。
- 既存の辺・角2,016条件を、休止からの上昇600°/秒、18°からの戻り420°/秒へ変更。左右・3半径・3更新間隔を含む。角をかすめる条件も含む。
- 計4,500条件。既存条件の参照を再利用し、新しい2,016条件は4,096区間＋22回絞り込み、2,048区間との一致を確認して参照を計算した。
- 最小隙間±0.1 px以内の35条件は分類を保留。分類対象4,465条件に参照接触2,206件。速度上限は前回同様3,600 px/秒。最初は非接触、重力・他の障害物なし。

| 検出結果（分類対象4,465条件） | B | D2 |
| --- | ---: | ---: |
| 誤接触 | 0 | 0 |
| 接触漏れ | 0 | 0 |
| 誤打球状態 | 3 | 0 |
| 打球状態の取りこぼし | 14 | 0 |
| 未解決（保留帯を含む4,500条件） | ― | 0 |

17件は全て追加した半径6・上昇中の上側の角をかすめる条件。B′の停止中の接触漏れとは別。Bも接触自体は検出するが、検出時刻が遅れることで法線が変わり、上面から60度という打球条件をまたぐ。

両方が接触した2,206条件の参照との差：

| --- | ---: | ---: |

D2の距離評価回数は中央値13、95%点125、最大1,032。固定間隔をなくしても、繰り返し計算自体がなくなるわけではない。上辺の動きに対して速度上限が大きい条件などでは、小刻みに進む。

### ゲーム上の影響を示す例

追加条件 `moving_edges/id87`：半径6、左板を休止から上げながら左上角をかすめる、60Hz。参照は通常反射。Godot AIで実行中のmainに同じ入力を与えた。

| 最初の応答 | B | D2 |
| --- | --- | --- |
| 検出時刻 | 8.3333 ms | 7.8703 ms |
| 打球扱い | あり | なし（参照と一致） |

方向は約51.52°異なる。大きな角度差は単に低速ベクトルの角度が不安定という例ではない。D2の精度改善には実際の応答を変える利点がある。ただし、この一例や17件はプレイ中の発生率ではない。

## 3. 同じ応答・回復へ接続した結果

上の検出試験で未解決と分類不一致0を確認してからD2を現行移動部品へ接続した。[quad_motion.gd](../quad_motion.gd) は回転計画だけをD2へ差し替える。停止中の標準判定、返球式、③、16回の上向き分離、接触上限8回は同じ。探索が未解決ならその更新は無効な比較とし、記録器はその件数・理由を保存する。最終実行では全て0だった。

### 既存2,628条件の1更新

全条件でBの終了位置が前回の測定と0.001 px未満で一致することを確認した。以下の位置誤差は**最初の応答後に残り時間を自由移動した終点**と、その同じ形式の参照との比較。実際の一更新全体の位置と混同しない。

| 更新 | Bの最大終点誤差 | D2の最大終点誤差 | Bの最大分離量 | D2の最大分離量 |
| --- | ---: | ---: | ---: | ---: |
| 30Hz | 4.135 px | 0.476 px | 3.878 px | 0.150 px |
| 60Hz | 2.873 px | 0.190 px | 3.007 px | 0.150 px |
| 120Hz | 2.605 px | 0.076 px | 3.076 px | 0.150 px |

これは既存の広い設定と現設定を合わせた値。D2でも最初から停止している板は標準判定なので、そちらの余裕幅・回復に由来する差は残る。

一方、一更新全体の反復では次の差が出た。

- Bは2,628条件全てで上限到達0。
- D2は30Hzのid405/465/525で上限8回に達し、各0.7518 ms、合計2.2554 msを捨てた。
- 3入力は上昇設定が異なるが、同じ45°からの戻り420°/秒を検査する同種の条件。3種類の独立した問題とは数えない。
- 全8接触で速度と時刻は変わっていた。約0.15 pxずつ離した後に戻る板と再接触し、最初2.975 msから最後32.582 msまで進んだ。無処理の反復を削除すれば済むという結果ではない。

精度を上げて補正量が小さくなっても、現在の応答ループの上限と両立するとは限らない。これをD2の誤検出と断定はしないが、そのまま置き換えた場合に新たな移動打ち切りが起きるという採用上の問題として扱う。

### 壁との順序・停止・③解除

回転する板への参照接触時刻を独立した参照で求め、垂直な試験壁への接触を板より−2／−0.1／0／＋0.1／＋2 msにした。壁は標準、板は各候補で検査し、同じ更新開始からの秒で先着を比較する。

- 2 ms以上離した条件はB/D2とも正しい先着を維持した。
- 差±0.2 ms未満のほぼ同時条件は別扱い。板が0.1 ms早い例ではBが壁、D2が板を先に処理したが、標準余裕を含むためこれを誤順序件数として加算しない。
- 休止・保持・上昇中の③解除と、更新途中の停止／停止後の次更新も各方式で確認した。これら10更新で未解決・上限到達0。

## 4. 検出時間と実装の単純さ

記録器を外した検出だけを測定。準備・形状のリセット・計画のコピー・参照・応答は時間外。1巡ウォームアップ後7巡、B/D1/D2の実行順を巡回させた。B/D1は同じ候補除外と検査時刻を使う。

| 入力群・問い合わせ数 | B：中央値［最小〜最大］ | D1 | D2 |
| --- | ---: | ---: | ---: |
| 既存876入力の60Hz回転計画828回 | 30.803［30.319〜31.710］ms | 31.212［30.620〜32.367］ms | 32.826［32.137〜33.960］ms |
| 追加の辺・角2,016回 | 67.241［61.116〜72.386］ms | 64.053［56.446〜78.349］ms | 234.019［220.939〜263.117］ms |

D1は既存入力でほぼ同じ、追加入力で中央値が約4.7%短いが範囲も重なり、本番の改善と結論する根拠は弱い。D2は既存入力で約6.6%遅く、辺・角入力で約3.48倍。異なる精度の比較であり、同じ精度の最速構成を証明するものではない。

同じ時刻を使うD1の距離評価数は、既存群14,312回、辺・角群26,101回。D2はそれぞれ16,172回、118,903回。固定間隔をなくしても、この入力分布では評価回数が減らなかった。Bの時刻ごとの距離評価回数はD1と同じだが、1回の処理内容は異なる。

D1は世界座標の四角形へ限定することで内外判定を直接書けるが、既存の多角形処理の再利用より明確に単純・高速とは言い切れない。D2はさらに速度上限、許容距離、停止区間、離脱の証明、未解決・反復上限の処理が必要。約4 px検査の単純なループより保守する内容が増える。

## 判断

1. **D1は本番へ採用しない。** 最初の接触は一致し、専用計算自体の正しさは確認できたが、負荷の明確な改善がなく、内部の同距離面や内外判定による応答差を導入する理由も弱い。
2. **D2の精度改善は有効な結果として残すが、採用は保留する。** 新しいBの打球状態不一致17件を解消し、最初の応答の位置誤差も減った。ただし、計算負荷・実装の複雑さ・新たな移動打ち切りがあり、同じ応答へそのまま差し替える条件は満たさない。
3. **Bの17件も未解決の課題として記録する。** Bが全条件で正しいとは扱わない。今後は、検出済み接触区間の少回数の絞り込み等とD2を同じ追加条件で比較する余地がある。今回は追加していない。
4. **本番B、停止中の標準、16回の分離、③、上限8回を維持。Cは未検証のまま。** 検出の精密化と、連続接触の応答・残り時間処理は別に採否を判断する。
