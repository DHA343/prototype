# 方式・組み合わせを分けた再検証

**2026-11-21追記：** [接触候補の実害を測った追加調査](contact_audit.md)で、開始点から終点へ直線移動する候補に誤ダメージ・接触漏れを再現した。その候補を第一候補とした下記の当初判断は撤回する。途中姿勢検査と全体時間分割の切り分けの測定結果は保持する。

## 結論

今回の範囲では、全体の物理更新を小刻みにする時間分割と、接触ごとの最大8回の経路再計算を、両方必須として残す根拠はなかった。検出の主候補は「全体の時間分割なし＋球とフリッパーを同時刻で調べる途中姿勢検査」。応答は、厳密な接触後の位置再現を要求しない今回の要件なら「終点へ一度移動し、そこで当たった対象にも応答」を第一候補にできる。

ただし終点応答は、最初の応答と終点の追加応答の最大2接触で、それ以降の連鎖は同じ更新内で追わない。現在の最大8回方式と最終位置・速度・細かな動作状態は同一にならない。比較用に「時間分割なし＋途中姿勢検査＋現在の接触反復」も残す。mainへの移植は行っていない。

## 共通条件と変えた処理

| 項目 | 条件 |
| --- | --- |
| 共通形状 | mainの接続点、左右Xと下端を固定した四角形、円形の球 |
| 検出の候補 | 終点重なり、更新後姿勢に対する球の直線移動、同時刻の途中姿勢検査、直線移動に単純な接近方向条件を追加 |
| 全体の時間分割 | なし＝1/60秒で1回更新、あり＝最大1/240秒＋回転量と半径に応じた追加分割 |
| 追加厚み | 0 / 48 px。0でも元の板に由来する厚さは残り、厚さゼロの線ではない |
| 応答 | 最初の1接触のみ、終点の追加接触にも応答、接触ごとの経路再計算最大8回 |
| ③の無効化 | 検出比較では無効。応答比較では有無を別に変更 |
| 参照判定 | 測定専用の4,096分割。2,048分割との分類一致を確認。半径±0.1 pxで分類が変わる境界例は保留 |

検出の途中姿勢検査も複数の時刻を検査する。これは球・敵・重力・壁応答を細かく更新する処理とは別で、全体の時間分割なしの候補にはその物理分割を入れていない。既存の4 px間隔に相当する姿勢サンプリングを検出専用に使う。

応答比較の壁・敵に対する直線移動判定と、食い込み解消にはGodot標準の移動判定を使う。壁の判定自体を別エンジンへ置き換える比較ではない。手動の上向き分離は既存の形状検査と二分探索を使う。終点方式と既存方式で分離を行う場面が異なることは、応答方式の一部として扱う。

## 1. 検出だけの比較

固定された球の直線経路とフリッパーの動きに対して検査した。打球、反射、食い込み補正、無効化を一切実行せず、どの候補も同じ経路を使う。

- 半径6/24/36 px、上昇速度300/600/1,200°/s、振り角18/45°、左右共通形状の左側を使用。
- 上昇開始・上げた状態からの戻り、上辺20/65/95%付近。
- 下向き3,600、上向き600/3,600、横向き3,600＋下向き600 px/s。先端を横切り、最後は板の外へ出る入力も含む。
- 各追加厚みについて540条件。全入力は初期非接触を確認。参照判定上の確実な接触は265条件、非接触は273条件、境界例2条件。
- 4検出方法×2分割設定×2厚みで16構成。参照密度による分類不一致は0。

追加厚み48 pxの結果：

| 検出方法 | 全体の時間分割 | 取りこぼし | 余分な接触候補 |
| --- | --- | ---: | ---: |
| 終点の重なりだけ | なし | 14 | 0 |
| 球の経路、フリッパーは更新後姿勢 | なし | 0 | 48 |
| 上と同じ＋接近方向の条件 | なし | 32 | 15 |
| 球とフリッパーの途中姿勢 | なし | 0 | 0 |
| 終点の重なりだけ | あり | 0 | 0 |
| 球の経路、フリッパーは更新後姿勢 | あり | 0 | 1 |
| 上と同じ＋接近方向の条件 | あり | 0 | 1 |
| 球とフリッパーの途中姿勢 | あり | 0 | 0 |

追加厚み0 pxでは、分割なし・終点重なりの取りこぼしが26へ増えた。他の構成の取りこぼし・余分な候補数は同じだった。

余分な候補は、必ずしも誤打球が発生した件数ではない。後段の接近方向や打球条件で速度変更を省略できる場合もある。ただし位置補正・余分な処理を生む可能性はある。更新後姿勢だけで球の経路を検査すると、異なる時刻に通った場所を接触と見なす例がある。単純な接近方向条件を付けた候補も試したが、この条件だけでは誤候補を除去しきれず、必要な接触まで除外した。

判断：厚みは取りこぼしを軽減するが、移動途中の検査を代替しない。全体の時間分割と途中姿勢検査は両方を使う必要はなく、今回の条件ではどちらかで対応できる。途中姿勢検査だけなら、他の球や敵まで細かく更新する必要がない。

## 2. 応答方式の比較

検出とは分離し、以下の応答を実装した。

| 応答候補 | 実装 |
| --- | --- |
| 最初の接触だけ応答 | 最初に見つけた接触から速度を変更し、終点を計算して一度安全に移動。終点で別の物に阻まれたら、その応答は次の更新へ回す |
| 終点の追加接触にも応答 | 上と同じ移動を行い、終点で当たった物にも反射・打球・ダメージを適用する。そこで再び移動経路を計算し直さない。最大2接触 |
| 現在の接触反復 | 接触位置まで動かして反射し、残り時間で経路を再計算。最大8接触 |

終点方式は最初の候補検出で得られる概算の接触時刻を使い、最初の速度と応答後の速度から終点を求める。接触時刻を高精度な根探索で詰める処理は追加していない。球を接触位置へ順次動かす処理を繰り返さない。終点の安全移動はGodotの標準衝突判定を使い、必要なら最後に上向き補正を行う。

終点で当たったフリッパーは終点姿勢とその更新での動きから応答を判断する。一更新内の厳密な停止時刻・連続衝突履歴を再現する方式ではない。入力・状態をどの更新の単位で有効とするかは、ゲーム仕様として扱う必要がある。

### 一更新内の複数接触

二枚の壁の間の試験では、球半径24、速度3,600 px/s、中心が動ける幅約42 px、反発係数1。一更新内で右壁に当たった後、左壁に到達する。

- 分割なし・最初の接触だけ応答：右壁だけ応答し、左壁は次回へ延期。
- 分割なし・終点の追加接触にも応答：右壁・左壁の両方に同じ更新で応答。
- 最大8回方式：同じく両方に応答するが、位置はさらに反射後の距離まで進む。

終点方式の最終Xは約927.19、最大8回方式は約940.56。約13.37 pxの差がある。接触対象を拾えることと、最終位置が同じことは別。

壁で反射した後に上昇中のフリッパーへ当たる試験も実施した。分割なしの最初の接触だけの候補は打球0、終点の追加接触にも応答する候補と最大8回方式は打球1。単に最初の応答で打ち切る候補は、この用途には不足している。終点方式では最大2接触以降の折れ曲がりを追わないため、3回以上の連鎖を同じ更新内で処理する要求は満たさない。

## 絞り込みと残る範囲

- 第一候補：全体の時間分割なし＋同時刻の途中姿勢検査＋終点の追加接触にも応答。厳密な位置再現より対象への反応を優先する要件に合わせる。
- 比較として残す候補：全体の時間分割なし＋途中姿勢検査＋現在の接触反復。負荷差は小さく、同一更新内の連鎖や位置再現を維持したい場合の比較対象。
- 時間分割＋終点判定だけも検出単独試験では成立したが、全体の更新数を増やす構成なので上記より優先しない。
- 厚みは保険として扱い、単独ですり抜けを防ぐ主方式とはしない。
- 位置補正・内部解除の問題は、どちらにも残る。共通移動部品への整理は未実装で、異なる種類の対象の追加時にどれだけコードが変わるかまでは測っていない。

この選定は、今回の形状・配置・速度範囲・更新頻度の範囲での候補の絞り込み。あらゆる角度、サイズ、初期食い込み、3回以上の連鎖、敵の密集状態での保証ではない。
