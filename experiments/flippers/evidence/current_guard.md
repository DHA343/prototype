# 現設定での③の復帰確認

## 結論

「球がまだフリッパーと重なっている間に③が解除される」状態は、低速設定に限らず現設定でも、近くの敵から早く戻る配置で再現した。今回の現設定試験では、解除した内部更新での新規打球は0件。低速試験で確認した再打球と、内部から通常接触へ復帰することを区別する。

| 条件 | 試験数 | 内部での解除 | 解除した更新での新規打球 |
| --- | ---: | ---: | ---: |
| 球・壁・フリッパーだけ | 7 | 0 | 0 |
| 同じ設定で近くに敵1体 | 84 | 22 | 0 |

近接配置を意図的に選んだ試験数であり、通常プレイでの発生率ではない。内部解除そのものが必ず不具合になるとも判定しない。戻った球を受け止めるのは意図した動作だが、重なり状態からの復帰では位置補正・通常反射と新規打球を分けて評価する必要がある。

## 固定した設定と試験範囲

- 振り角18°、上昇速度600°/s、根元返球角−20°・先端返球角40°、威力均等化0.5。
- 球半径24 px、重力1,500 px/s²、速度上限3,600 px/s、ダメージ50。固定幅・追加厚み48 px、穴幅84 px。
- 左上辺5/15/30/50/70/90/99%の位置で、球を半径＋4 px上に離し、下向き300 px/sから開始。左右を同時に上げる。
- 敵は既存の `enemies/enemy.tscn`。半径30 px、反発係数0.8、HP100、通常のダメージ・ノックバック・フリッパーとの衝突を使用する。成長演出が終わった状態から開始する。
- 敵の初期中心は球中心から上へ「両者の半径の合計＋3/12/36/72 px」、横へ−36/0/36 px。縦方向の余裕3 pxかつ横差0のとき、初期の球と敵の表面間隔は3 pxで、初期重なりはない。
- 各条件を1秒追跡。mainと同じ順にフリッパー、敵、球を更新する。敵の経路移動・群衆の押し出し・スポーン全体は含めず、敵は衝突のノックバック等で動く。main全体での自然発生頻度を測ったものではない。

## 実際の経路の例

左上辺5%、敵を球の真上へ表面間隔3 pxで置いた条件：

1. 約9.17 msで左から打球。球の速度は約(−478, −1,553) px/s。
2. 敵に反射して下向きへ変化。
3. 約16.67 msの復帰チェックでは、速度が約(−566, +1,207) px/sで、左フリッパーとの重なり深さが約0.97 pxあった。
4. ③が解除され、通常接触と分離を処理。新規打球は発生せず、その更新終了時の速度は約(−553, −264) px/sとなった。

計算上の重なりは、復帰チェック時に使用する更新後のフリッパー形状で計測している。細かな衝突時刻における厳密な侵入量を意味するものではない。

## 評価の更新

- 前の打角・速度変更試験で「300°/s以上は内部解除未検出」としたのは、その試験範囲での結果。近い敵を入れた今回の試験では600°/sで内部解除を検出した。
- したがって「極端な設定でだけ見える問題」として片づける根拠はない。
- 現設定で、低速試験と同じ新規打球が十分な頻度で発生すると判断する根拠もまだない。今回の解除時の新規打球は0件。
- ③の復帰条件は下降速度のみで、球がフリッパーから完全に離れた履歴・解除時の重なりを条件にしていない。設定に依存せずこの経路へ入れる構造である。

今回の機械的検査91件は位置が有限であることを確認する検査。内部解除がないことや、新規打球・位置補正が解決済みという成功判定ではない。本体の無効化・衝突処理は変更していない。
